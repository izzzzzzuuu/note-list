This project for basic note taking / CRUD app

to run:
- Highly recommends to install required packages in virtual environment instead of global environment with command "python -m venv <env-name>"
- once virtual environment created, run the below command
- need to install the required packages with command "pip install -r requirements.txt"
- After installing packages in virtual environment, dont forget to activate it before running the code : "<env-name>/scripts/activate"  (you can decativate it just by using "deactivate")
- command to run "uvicorn app.main:app --reload"
